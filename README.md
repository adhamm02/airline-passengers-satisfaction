## 📖 Overview

This project analyzes passenger data and predicts whether a passenger is **Satisfied** or **Neutral/Dissatisfied** with their flight experience. It uses a trained machine learning model, taking into account various factors such as flight distance, class, delays, and in-flight service ratings. 

## ✨ Features

- **Predictive Modeling**: Uses a pre-trained machine learning classifier to evaluate passenger satisfaction.
- **Interactive Web Interface**: A clean, modern UI built with Flask to easily input passenger details.
- **Data Analysis**: Includes Jupyter notebooks detailing the Exploratory Data Analysis (EDA) and model training processes.
- **Scalable Architecture**: Uses `joblib` for efficient model serialization and loading.

## 🛠️ Tech Stack

- **Backend**: Python, Flask
- **Machine Learning**: Scikit-learn, NumPy
- **Frontend**: HTML, CSS, JavaScript
- **Model Serialization**: Joblib

## 🚀 Getting Started

### Prerequisites

Make sure you have Python 3.8+ installed on your machine.

### Installation

1. **Navigate to the project directory:**
   ```bash
   cd "airline satisfaction project"
   ```

2. **Create a virtual environment (Optional but recommended):**
   ```bash
   python -m venv venv
   # On Windows:
   venv\Scripts\activate
   # On macOS/Linux:
   source venv/bin/activate
   ```

3. **Install the dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

### Running the App

1. Ensure that the `artifacts/` folder contains the required model files (`best_model.pkl`, `input_scaler.pkl`, etc.). These are generated by running the training notebook.
2. Start the Flask server:
   ```bash
   python app.py
   ```
3. Open your web browser and navigate to `http://127.0.0.1:5000/`.

## 🧠 Machine Learning Process

The model training process is documented in `notebooks/BIG_DATA_final.ipynb`. The pipeline includes:
- **Data Preprocessing**: Handling missing values and scaling numerical features.
- **Feature Encoding**: Categorical variables (Gender, Customer Type, Class, Travel Type) are encoded.
- **Model Training**: Evaluating various algorithms to find the best performing classifier.
- **Evaluation**: The best model is serialized into the `artifacts/` folder for production use.

## 📊 Inputs Needed for Prediction

The application requires the following inputs:
- **Demographics**: Gender, Age, Customer Type
- **Flight Details**: Flight Distance, Type of Travel, Class
- **Delays**: Departure Delay in Minutes, Arrival Delay in Minutes
- **Service Ratings (0-5)**: Inflight WiFi, Departure/Arrival time convenience, Ease of Online booking, Gate location, Food and drink, Online boarding, Seat comfort, Inflight entertainment, On-board service, Leg room service, Baggage handling, Check-in service, Inflight service, Cleanliness.
